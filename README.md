## 训练规则

1. 先遮住标准答案，自己口述。
2. 一次只答一道，根据回答追问。
3. 评价：现象、分层、命令是否准确、证据顺序、变更风险、验证、回滚。
4. 说「不会 / 直接教我」则改讲解，不再硬评分。
5. 命令要能默写，不能只说「看日志 / 看防火墙」。
